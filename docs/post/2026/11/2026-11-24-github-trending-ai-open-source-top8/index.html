1. Superpowers: 코드를 쓰기 전에 질문하고 계획하기

Superpowers는 Claude Code 같은 코딩 에이전트에 브레인스토밍·계획·구현·리뷰 절차를 스킬로 제공하는 프레임워크입니다. 영상에서는 사용자가 “간단한 앱을 만들어 달라”고 요청해도 에이전트가 곧바로 코드를 생성하지 않고, 무엇을 왜 만드는지 되묻고 선택지와 추천안을 제시하는 장면을 보여 줍니다. 이후 설계 문서와 작은 작업 목록을 만들고, 작업별 보조 에이전트와 테스트 우선 흐름을 적용합니다. 영상 0:24

핵심은 AI의 능력을 키우는 것이 아니라 성급한 구현을 늦추는 안전장치를 넣는 것입니다. 요구사항이 모호한 기능, 여러 화면에 걸친 큰 변경, 팀 리뷰가 필요한 작업에 적합합니다. 반대로 한 줄짜리 수정까지 계획 절차를 거치면 오버헤드가 커질 수 있으므로 작업 크기에 따라 선택해야 합니다.

2. Last 30 Days: 커뮤니티 반응을 근거와 함께 요약하기

Last 30 Days Skill은 Reddit, Hacker News, X, YouTube, Polymarket과 웹에서 최근 반응을 모아 출처 링크가 있는 요약을 만드는 에이전트 스킬입니다. 영상에서는 플러그인 명령 두 줄로 설치한 뒤 개발 도구를 주제로 검색하고, 출처별 결과와 링크를 한 장의 요약으로 받는 과정을 보여 줍니다. 영상 1:28

이 도구의 가치는 “인터넷 여론이 이렇다”는 결론보다 어떤 출처에서 어떤 기간의 신호를 모았는지를 빠르게 확인하는 데 있습니다. 영상은 무료 출처로 Reddit·Hacker News·Polymarket·GitHub를 살펴볼 수 있고, 최신 버전에서는 회사 이름을 넣어 특허 출원과 채용 페이지의 단서도 찾는다고 설명합니다. 검색 결과는 표본과 검색어에 의존하므로 의사결정 전에 원문을 다시 읽어야 합니다. 영상 2:05

3. CLI-Anything: GUI 프로그램을 에이전트의 CLI로 바꾸기

CLI-Anything은 GUI 중심 소프트웨어를 에이전트가 호출할 수 있는 CLI 형태로 연결하는 허브와 생성기를 제공합니다. 영상에서는 Blender를 설치한 뒤 에이전트가 명령어로 3D 물체를 만들고 렌더 이미지를 저장합니다. 사용자는 화면을 클릭하지 않았지만, 에이전트는 Blender CLI를 찾아 여러 명령을 순서대로 실행합니다. Draw.io 흐름도 생성 사례도 같은 구조입니다. 영상 2:25

프로젝트의 생성기는 소스 코드가 있는 프로그램을 대상으로 전용 CLI를 만드는 단계별 절차를 제공합니다. 반대로 내부 호출 지점이 없는 폐쇄형 화면 앱은 겉모습만 자동화될 수 있으므로, “모든 GUI를 완벽하게 조작한다”는 의미로 받아들이면 안 됩니다. 영상 3:39

4. Firecrawl: 웹을 에이전트가 읽는 Markdown으로 바꾸기

Firecrawl은 웹페이지를 크롤링·검색해 AI가 읽기 쉬운 Markdown으로 변환하는 도구입니다. 영상은 Firecrawl Local을 MCP로 Claude Code에 연결하고, 최신 뉴스를 요청해 웹 페이지 내용을 Markdown 파일로 저장하는 흐름을 보여 줍니다. 로컬 실행을 사용하면 크롤링 결과를 에이전트 작업 디렉터리로 바로 넘길 수 있다는 점이 핵심입니다. 영상 4:01

영상에서는 과거 로컬 설치에 여러 Docker 서비스가 필요했지만, 새 실행 파일 방식은 단일 바이너리로 구성할 수 있고 메모리 사용량도 크게 줄였다고 소개합니다. 다만 기본 설정이 로컬과 클라우드 혼합일 수 있으므로, 클라우드 크레딧과 데이터 경계를 분명히 하려면 설정을 확인해야 합니다. 영상 4:43

5. Ghost Downloader: 원하는 구간만 받는 멀티 프로토콜 다운로드

Ghost Downloader는 일반 파일·토렌트·스트리밍을 Windows, macOS, Linux, Android에서 다루는 다운로드 앱입니다. 영상에서는 브라우저 영상 위에 나타난 다운로드 버튼으로 타임라인의 필요한 구간만 선택하고, 입력 방식에 따라 서로 다른 엔진이 작업을 처리하는 모습을 보여 줍니다. 영상 5:01

이전 포스트에서 다룬 것처럼 공식 저장소는 HTTP, Magnet/BT, FTP, M3U8, MPEG-DASH, eD2k와 미디어 스니핑을 지원한다고 설명합니다. 영상의 속도 비교는 특정 느린 링크와 특정 연결 조건의 사례이며, 실제 성능을 보장하는 수치가 아닙니다. 영상 5:25

6. App Store Compliance: 제출 전 거절 위험을 코드로 점검하기

App Store Compliance는 앱스토어와 Google Play에서 반복되는 거절 패턴을 정리하고, 제출 전에 프로젝트를 검사하는 도구입니다. 영상은 124개의 거절 패턴을 기반으로 샘플 iPhone 앱을 검사하고, 위험 항목·수정 지침·최종 BLOCKED 상태를 확인한 뒤 문제를 고쳐 CLEAR로 바꾸는 과정을 보여 줍니다. 영상 5:55

AI 코딩 에이전트의 배포 명령 직전에 검사를 걸면 명백한 누락을 자동으로 막을 수 있지만, CLEAR가 스토어 심사 통과를 보장하지는 않습니다. 코드 검사만으로는 데모 계정, 스크린샷, 개인정보 처리 문서처럼 사람이 준비해야 하는 제출 항목을 판단할 수 없기 때문입니다. 영상 6:39

7. MiniMind: 작은 모델을 직접 학습하며 원리 이해하기

MiniMind는 언어 모델의 토큰화, 사전학습, 정렬, 도구 호출을 작은 규모로 따라가며 학습하는 교육용 프로젝트입니다. 영상은 약 6,400만 파라미터 모델을 처음부터 학습시키고, 대화·코드 생성·계산 도구·날씨 도구 호출을 확인합니다. 영상 6:56

영상에 나온 “3090 한 장으로 약 두 시간, 약 3위안”이라는 비용은 특정 하드웨어와 설정에 대한 사례입니다. MiniMind의 목적은 상용 거대 모델을 대체하는 것이 아니라, 모델이 데이터를 읽고 가중치를 조정하며 외부 도구를 호출하는 과정을 직접 관찰하게 하는 데 있습니다.

8. ECC: 계획·테스트·구현·리뷰의 순서를 강제하기

ECC는 Claude Code, Codex, OpenCode, Cursor 등에서 사용할 수 있는 에이전트 스킬·메모리·보안·연구 우선 개발 규칙을 묶은 저장소입니다. 영상에서는 플러그인을 설치한 뒤 계획 명령을 실행하고, 에이전트가 코드를 쓰기 전에 단계별 계획을 제시한 뒤 사람이 승인할 때까지 대기하는 흐름을 보여 줍니다. 영상 8:00

필요한 에이전트와 스킬만 골라 설치할 수 있다는 점은 장점입니다. 반대로 저장소 전체를 한 번에 로드하면 대화 시작부터 컨텍스트 창을 차지하므로, 프로젝트에 필요한 규칙만 선택적으로 가져오는 편이 좋습니다. 영상 8:40

어떤 순서로 도입할까

8개를 한 번에 설치하면 도구보다 설정 관리가 더 어려워집니다. 먼저 Superpowers나 ECC 중 하나로 에이전트의 계획·승인 흐름을 만들고, 정보 조사 작업이 많을 때 Last 30 Days와 Firecrawl을 추가하는 순서가 안전합니다. Blender·Draw.io처럼 CLI 연결이 필요한 작업이 있을 때 CLI-Anything을, 미디어 수집이 필요할 때 Ghost Downloader를 붙입니다. 모바일 앱을 출시한다면 Compliance를 배포 게이트로 두고, 모델 원리를 공부하려는 경우에만 MiniMind를 별도 학습 프로젝트로 운영하세요.

핵심 요약

  • Superpowers·ECC: 에이전트가 코드부터 쓰지 않고 질문·계획·테스트·리뷰 순서를 따르게 합니다.
  • Last 30 Days·Firecrawl: 최신 커뮤니티 반응과 웹 문서를 에이전트가 조사할 수 있는 형태로 바꿉니다.
  • CLI-Anything·Ghost Downloader: GUI 프로그램과 미디어 다운로드를 명령·작업 큐로 연결합니다.
  • App Store Compliance: 제출 전 코드 수준의 거절 위험을 점검하지만 심사 통과를 보장하지는 않습니다.
  • MiniMind: 작은 모델을 직접 학습해 토큰화·학습·도구 호출 원리를 익히는 교육용 프로젝트입니다.
  • 도구는 인기 순서가 아니라 현재 병목에 맞춰 하나씩 도입해야 하며, 별 개수·성능·비용 수치는 시점과 환경을 함께 확인해야 합니다.

결론
