PPT Master는 ‘PPT를 만드는 앱’보다 에이전트 워크플로우에 가깝다

기획서에서 슬라이드로: 먼저 청중과 메시지를 확정한다

발표자는 2026년 하반기 마케팅 팀 워크숍 기획안을 프로젝트 폴더에 넣고, Claude Code에 이를 PPT로 만들어 달라고 요청한다. 에이전트는 곧바로 그림부터 그리기보다 누구에게, 어떤 목적으로 보여 주는지, 화면 비율, 장수, 디자인 방향, 이미지 제공 방식, 발표자 노트 여부 등을 확인한다. 영상에서 보이는 ‘시놉시스’와 디자인 확인 화면은 발표 자료를 만들기 전의 계획 승인 단계다. 문서를 단순히 페이지별로 잘라 넣는 작업과 다르게, 발표 순서와 핵심 메시지를 먼저 정하려는 것이다. 영상 03:08, 영상 03:48, 영상 04:38

이미지·영상은 선택적 확장이지 기본 PPT 생성의 필수 조건이 아니다

영상은 PPT의 배경과 분위기를 위해 별도 이미지·영상 생성 서비스를 연결한다. 발표자는 외부 서비스의 MCP 주소를 Claude에 등록해 워크숍 이미지와 짧은 영상 컷을 만든 뒤 슬라이드에 넣는 흐름을 보여준다. 이는 PPT Master 자체의 PPTX 작성 기능과 외부 서비스의 시각 자료 생성 기능을 합친 사례다. MCP 연결만으로 PPT Master에 영상 생성 모델이 내장되는 것은 아니다. 외부 계정의 크레딧, 생성 결과의 사용 조건, 슬라이드 안에서의 재생 호환성은 각각 확인해야 한다. 영상 06:30, 영상 06:49, 영상 07:38

무료 오픈소스와 실제 작업 비용은 다르다

PPT Master 저장소는 MIT 라이선스의 오픈소스이며, 공식 README는 별도의 PPT 서비스 구독료 없이 로컬에서 파이프라인을 실행한다고 설명한다. 동시에 AI 모델 토큰 사용량이 많을 수 있다고 명시한다. 영상에서도 모델 사용료와 선택적 이미지·영상 크레딧을 따로 언급한다. 그러므로 ‘스킬 자체가 무료’는 맞지만, 완성 발표 자료의 총비용이 0원이라는 뜻은 아니다. 파일 준비, 디자인 승인, 결과 검수에 드는 시간도 계산에 넣어야 한다. 영상 02:15, PPT Master 공식 README

설치도 ‘저장소 링크를 붙여 넣는 한 문장’만으로 일반화하기 어렵다. 영상에서는 Claude Code에 GitHub 주소를 주고 설치를 요청하지만, 공식 README에는 Python 3.10~3.14와 프로젝트 의존성 설치가 전제로 나온다. 실제 사용 전에는 최신 공식 설치 안내를 확인하고, 외부 저장소 코드를 실행해도 되는 환경인지 살펴야 한다. 공개 자료를 입력할 때와 달리 회사 내부 기획안을 다룰 때는 연결된 모델·검색·이미지 서비스로 어떤 내용이 전송되는지도 점검해야 한다. 영상 02:51, PPT Master 공식 README

실전 적용 포인트

처음 시험할 때는 기밀 자료가 아닌 짧은 문서 한 개로 시작해, 청중·목적·슬라이드 수·화면 비율·원본에 없는 사실을 채우지 말라는 조건을 명시하면 좋다. 시각 자료는 첫 실험에서 제외하고, 핵심 메시지와 PPTX 객체의 편집성을 먼저 확인한다. 이후 필요한 이미지나 B-roll만 추가하면, 내용 오류와 외부 생성 비용을 분리해 평가할 수 있다. 이는 영상과 공식 문서의 절차를 검증 가능한 작은 실험으로 재구성한 제안이다. 영상 03:48, 영상 05:34, PPT Master 공식 README

최종 검수에서는 원문 대비 숫자·날짜·결론, 슬라이드별 한 가지 메시지, 텍스트 넘침, 표의 읽기 쉬움, 실제 PowerPoint에서 객체가 선택되는지, 미디어가 재생되는지를 각각 확인해야 한다. 데이터 연결 차트가 필요하면 기본 도형 차트와 구별해 별도 옵션의 산출물을 확인한다. 발표자 본인도 PPT Master를 ‘처음부터 끝까지 다 해 주는 도구’가 아니라 뼈대와 레이아웃을 잡는 도구로 정리한다. 영상 08:49, 영상 09:05, PPT Master 공식 README

핵심 요약

  • PPT Master는 에이전트가 자료를 분석하고 계획·페이지 제작·PPTX 출력을 수행하는 스킬 기반 워크플로우다. 영상 01:48
  • 결과 PPTX는 편집 가능한 객체를 목표로 한다. 다만 기본 차트·표와 데이터 연결형 네이티브 차트·표는 출력 옵션이 다르다. 영상 00:58, 공식 README
  • 영상의 이미지·영상 생성은 외부 서비스 연결을 사용한 선택적 확장이다. 모델·미디어 비용은 오픈소스 사용료와 별개다. 영상 06:49
  • 일정·예산·수치와 디자인 완성도는 사람이 검수해야 한다. 영상 09:05

결론

PPT Master의 가치는 발표 자료의 구조와 편집 가능한 초안을 빠르게 만드는 데 있다. 자동화가 줄여 주는 수작업은 크지만, 메시지의 정확성과 최종 발표 품질을 책임지는 검수까지 대신하지는 않는다.
